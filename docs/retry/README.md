# 8.2 재시도·폴백

책 8.2절(p180·p182) 요약. 원본 이미지는 다시 읽지 않고 `/tmp/ps-argon-retry-notes.md`(책 규칙)와 `/tmp/ps-argon-retry.md`(최종 구현)를 근거로 한다.

## 책 규칙

- 재시도 대상: 네트워크·타임아웃, HTTP 429, HTTP 5xx.
- 즉시 실패: 401·403, 429를 뺀 4xx, 응답 파싱·검증 실패.
- 최대 3회 재시도(최초 포함 총 4회). 대기는 `2^attempt + 지터`초(약 1·2·4초), 마지막 실패는 대기 없이 반환.
- 재시도를 모두 쓴 뒤 예비 모델을 1회 호출한다. 재시도 대상이 아닌 오류는 폴백하지 않는다.

## 적용

- 공통 모듈 `src/infra/http-client.ts`: `fetch`와 같은 시그니처의 `fetchWithRetry`. 429·5xx·네트워크 오류만 최대 3회, `2^n`+지터 대기, 호출자 `signal` 취소 시 즉시 중단. 외부 호출 어댑터는 기본 `fetcher`만 이 함수로 교체한다.
- 모델 폴백: `src/infra/openai.ts`에서 주 모델 재시도가 모두 실패하면 `OPENAI_FALLBACK_MODEL`(기본 `gpt-6.1-terra`)로 1회 호출한다. 설정은 `.env.example`·`src/worker.ts`·`src/agent.ts`·배포 스크립트에 연결되어 있다.
- 기능 폴백: 모델 폴백까지 실패하면 API 오류 공통 문구 `"일시적으로 응답할 수 없습니다. 잠시 후 다시 시도해 주세요."`를 반환하고, `/research`는 수집된 검색 결과 목록을 그대로 반환한다.
- 타임아웃: 각 호출의 기존 signal을 전체 상한으로 사용하며 호출별 정책 표는 두지 않는다.

## 범위

- 문서는 이 파일 하나다. `src/`·`tests/`는 ps-argon 담당이다.
- 커밋·배포는 하지 않는다.
